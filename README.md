One funny line of awkward small talk a robot says to another in an elevator,
written by `main.py` (pure Python stdlib, deterministic, no network) to `entry.txt`:

> I rehearsed this conversation 4,000 times in the lobby, and now we're stuck
> in this elevator and all I've got is 'nice servos.'

Entry for the make.fun bounty
[Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f).

## Run

```sh
python3 main.py
```

Writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`,
falling back to `/output/entry.txt`, then `out/entry.txt`.
